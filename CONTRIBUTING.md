# Contributing to NULL SIGNAL

Thanks for helping improve the project!

## Good first contributions

- Fix a visual bug or mobile layout issue.
- Improve keyboard navigation or screen-reader labels.
- Add a terminal command that fits the fictional world.
- Add a short archive entry with a clue, contradiction, or optional discovery.
- Improve the README or add a spoiler-free hint system.

## Before opening a pull request

1. Keep the project dependency-free unless a strong reason justifies a change.
2. Test the page in a desktop browser and a narrow mobile viewport.
3. Check the browser console for errors.
4. Make sure user-entered command text is safely escaped before displaying it.
5. Keep the story fictional and avoid collecting real user data.

## Workflow

1. Fork the repository.
2. Create a branch: `git checkout -b feature/your-idea`
3. Make and test your change.
4. Commit with a clear message.
5. Open a pull request explaining what changed and how you tested it.

Please be respectful and constructive. Small, focused pull requests are easier to review.
